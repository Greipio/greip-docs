Each API has its own limitation rules. These rules helps the service being more secure by returning error messages to the requests detected by the system's security rules.

Each plan includes a monthly request quota (1,000 requests during the 3-day trial, then the full Standard or Premium quota after you convert). The API also rate-limits clients that send more than **1,000 requests per second**.

If you exceed your plan quota, the API returns `limit_reached` (code 103). If the account has no active trial or paid subscription, it returns `subscription_required` (code 127).

<Tip>
  Note that you can check your API usage in real-time from your account
  dashboard
</Tip>
