### Path parameters

<ParamField path="phone" type="string" required placeholder="Phone number">
  The phone number you want to validate.

  Expected values: a phone number

  Sample value: `+12121234567`, `0012121234567`, `12121234567`, or `2121234567`
</ParamField>

### Query parameters

<ParamField query="country_code" type="string" required placeholder="Country code">
  The `ISO 3166-1 alpha-2` format of the country code of the phone number. [Learn more](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2)

  Sample value: `US`
</ParamField>

    <ResponseField name="risk_level" type="string" required>
      Overall risk band (`low`, `medium`, or `high`).
    </ResponseField>
    <ResponseField name="recommendation" type="string" required>
      Suggested action (`accept`, `review`, or `reject`).
    </ResponseField>
    <ResponseField name="reasons" type="array" required>
      Human-readable strings explaining elevated risk. Empty when `risk_level` is `low`.
    </ResponseField>
    <ResponseField name="is_valid" type="boolean" required>
      Whether the number passes structure and validation checks for the given `country_code`.
    </ResponseField>
    <ResponseField name="is_blacklisted" type="boolean" required>
      Indicates if the phone number is blacklisted due to applying [custom
      rules](/knowledge-base/custom-rules/overview) or were found in one of your
      blacklists.
    </ResponseField>
    <ResponseField name="is_disposable" type="boolean" required>
      Whether the number is flagged as disposable or spam.
    </ResponseField>
    <ResponseField name="phone" type="string" required>
      The phone number you sent in the request.
    </ResponseField>
    <ResponseField name="country_code" type="string" required>
      The country code you sent in the request (ISO 3166-1 alpha-2).
    </ResponseField>

              The rule title you set when creating the rule.
            </ResponseField>
          </Expandable>
        </ResponseField>
