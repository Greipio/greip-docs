Use `GET /lookup/ip/{ip}` when you already know the address to look up. Put the address in the path, not in the query string. For the visitor IP on the current request, use [IP Geolocation](/api-reference/v2/endpoint/data-lookup/geoip) (`GET /geo/ip`) instead.

### Path parameters

<ParamField path="ip" type="string" required placeholder="IP address">
  The IP address you want to look up.

  Expected values: an IP address (IPv4 or IPv6)

  Sample value: `1.1.1.1`
</ParamField>
