`GET /geo/ip` resolves the IP address of the current request and returns the same rich `data` object as [IP Lookup](/api-reference/v2/endpoint/data-lookup/ip) (geo, optional modules, and related fields). To look up a different address, use the IP in the path on `GET /lookup/ip/{ip}`, not a query parameter.
