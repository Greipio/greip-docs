To attribute events in the Greip dashboard to a user in your system, pass the `user_id` query parameter on supported requests (v1 alias: `userID`).

Examples (API v2):

```
https://v2.greipapi.com/lookup/ip/1.1.1.1?user_id=john@example.com
```

```
https://v2.greipapi.com/lookup/ip/1.1.1.1?user_id=John
```

<V2DocsAuthNote />

When you include `user_id`, you can identify and track fraudulent activities on the [Events page](https://dashboard.greip.io/events) using values such as email, phone, or an internal user id.

<Frame caption="Greip Dashboard - Real-time events page">

![Greip Dashboard - Real-time events page](/images/events-user-id.png)

</Frame>

<Warning>
**Important**

You do not need `user_id` on [Payment Fraud Detection](/api-reference/v2/endpoint/scoring/payment) requests. Greip derives the identifier from fields such as `customer_email`, `customer_phone`, or `customer_id` in the payment payload.

</Warning>
