Our API provides flexibility in the format of the response, allowing you to customize the response format to best suit your needs. Whether you prefer `JSON`, `XML`, `CSV`, or `Newline` formats, we've got you covered.

To change the format of the API response, add the `format` parameter to your API request and specify the desired format type. JSON is the default format, so you do not need this parameter for JSON responses.

The available values for `format` are: `JSON`, `XML`, `CSV`, and `Newline`.

## Usage

For example, to retrieve data in XML format:

```bash cURL
curl -G 'https://v2.greipapi.com/geo/ip' \
  --data-urlencode 'params=location' \
  --data-urlencode 'format=XML' \
  -H 'Authorization: Bearer <api-key>'
```
