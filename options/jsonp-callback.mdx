Our API supports JSONP (JavaScript Object Notation with Padding) callbacks. Add the `callback` parameter with a valid JavaScript function name and the JSON response is wrapped for use in cross-domain scripts. JSONP works with the `JSON` format only.

Example request (API v2):

```
https://v2.greipapi.com/geo/ip?callback=myFunctionName
```

Send your API key with `Authorization: Bearer <api_key>` on the request. JSONP does not replace Bearer authentication on v2.

## Sample response

The browser receives executable JavaScript. With API v2, the payload uses the standard success envelope and nested `data` object:

```javascript
myFunctionName({
  "success": true,
  "data": {
    "ip": {
      "address": "68.235.60.237",
      "version": 4,
      "numeric": 1156267245,
      "bogon": false
    },
    "geo": {
      "continent": "North America",
      "continent_code": "NA",
      "country": "United States",
      "country_code": "US",
      "region": "Illinois",
      "city": "Chicago",
      "postal": "60605",
      "latitude": 41.8672,
      "longitude": -87.6259
    }
  },
  "execution_ms": 4
});
```
