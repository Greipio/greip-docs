To access our API and take advantage of all the available methods, you will need to authenticate your requests using your unique API Key. This key is a secure authentication mechanism that ensures only authorized users can access the API.

To obtain your API Key, navigate to your [account dashboard](https://dashboard.greip.io/home).

## API v2 (recommended)

Send the key in the `Authorization` header on every request to `https://v2.greipapi.com`:

```bash cURL
curl --request GET \
  --url 'https://v2.greipapi.com/geo/ip' \
  --header 'Authorization: Bearer <api-key>'
```

Do not pass the API key as `?key=` or in a JSON `key` field on v2. That returns `invalid_params` (104). See [Migration](/migration).

## API v1 (Legacy)

On the legacy host (`https://greipapi.com`), you may pass the key in the query string:

```bash
https://greipapi.com/geoip?key=1234567890
```

Bearer authentication is also supported on v1:

```bash cURL
curl --request GET \
  --url https://greipapi.com/geoip \
  --header 'Authorization: Bearer <api-key>'
```

## Securing your API Key

For more information about how to secure your API Key, please refer to [Protecting your API Key](https://docs.greip.io/knowledge-base/account-management/protecting-your-api-key).
